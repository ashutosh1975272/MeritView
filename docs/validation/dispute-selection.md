# Dispute Selection Template

## Purpose

## Selection Criteria
- [ ] Real dispute (not synthetic)
- [ ] Contract type diversity (service, sales, lease, employment, etc.)
- [ ] Stake range ($1K–$100K+)
- [ ] Available from professional network (colleagues, mentors, alumni)
- [ ] Parties willing to share anonymized details
