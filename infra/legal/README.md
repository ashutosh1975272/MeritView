# Legal Documents

This directory contains legal documents and disclaimers for MeritView.

## Contents

- `disclaimers/` — Standard disclaimers included in opinion reports
- `terms-of-service/` — ToS drafts and final versions
- `privacy-policy/` — Privacy policy drafts and final versions

## Disclaimer Versioning

Disclaimers are versioned using semantic versioning. The current disclaimer version is defined in `backend/src/services/opinions/index.ts`.

## Legal Review Cadence

Legal review occurs quarterly. See `docs/legal-review-checklist.md` for the review process.
