# Legal Review Checklist

## Quarterly Review Cadence

- [ ] Review all standard disclaimers for regulatory compliance
- [ ] Check for changes in UPL (Unauthorized Practice of Law) regulations
- [ ] Verify "decision support, not legal advice" framing remains accurate
- [ ] Review prohibited jurisdictions list
- [ ] Update disclaimer version if changes are made

## Release Gate

- [ ] Legal review passed for current disclaimer version
- [ ] All opinion reports include minimum 4 standard disclaimers
- [ ] SEO/meta pages include disclaimer language
- [ ] Disclaimer version matches between backend and documentation
